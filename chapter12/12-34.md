---

## ✅ **1. What Is Being Asked?**

You're asked to:

1. **Write a matrix multiplication kernel**: A function that multiplies an N×M matrix A with an M×P matrix B and stores the result in an N×P matrix C.
2. **Create a parallel threaded version** using `pthreads`.
3. **Compare the performance** of the **parallel version** with a **sequential (single-threaded) version**.

---

## 🧮 **2. Matrix Multiplication Recap**

For matrices:

* `A[N][M]`
* `B[M][P]`
* Result: `C[N][P]`

Each element:

```c
C[i][j] = sum over k of A[i][k] * B[k][j]
```

---

## 🧵 **3. Threaded Version (What to Parallelize)**

You can parallelize by:

* Assigning **each row** of matrix C to a separate thread.
* Or even each **element** `C[i][j]` to a thread (too many threads — not efficient unless small matrices).
* Best tradeoff: **One thread per row**.

---

## 🧪 **4. How to Compare Performance**

Use `gettimeofday()` or `clock_gettime()` to measure time taken:

* Time the sequential multiplication.
* Time the threaded multiplication.
* Compare both (speedup = time\_seq / time\_parallel).
