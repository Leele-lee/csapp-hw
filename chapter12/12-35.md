# 12-35

## Question

> Implementa concurrent version of the TINY Web server based on processes.Your solution should create a new child process for each new connection request. Test your solution usinga real Web browser

## Reference

P976 chapter 12

## Code

- don't forget reap all child using `SIGCHLD` handler

```c
void sigchld_handler(int sig) {
    while (waitpid(-1, 0, WNOHANG) > 0) 
        ;
    return;
}
```

- create a child for each new connect socket

```c
  while (1) {
    clientlen = sizeof(clientaddr);
    connfd = Accept(listenfd, (SA *)&clientaddr, &clientlen); //line:netp:tiny:accept
    Getnameinfo((SA *) &clientaddr, clientlen, hostname, MAXLINE,
        port, MAXLINE, 0);
    printf("Accepted connection from (%s, %s)\n", hostname, port);

    // forking child
    if (Fork() == 0) {
      Close(listenfd);
      doit(connfd);  // line:netp:tiny:doit
      Close(connfd);
      exit(0);
  }
  Close(connfd); // line:netp:tiny:close
  }
```
